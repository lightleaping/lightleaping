# 공통 기본기 학습

목표: Python부터 Agent까지 필요한 개념을 작은 코드로 확인하고 실제 프로젝트에 적용합니다. 학습용 기록이며 별도 완성형 대표 프로젝트로 취급하지 않습니다.

## 방식

현재 수준 확인 → 작은 과제 → 본인 구현 → 코드 리뷰 → 수정 → 이해 확인 → 프로젝트 적용.

문서 참고는 허용합니다. 그대로 복사해 실행하는 것만으로 완료 처리하지 않습니다. 모든 기초를 끝낼 때까지 프로젝트를 미루지 않고, 막힌 부분을 보충합니다.

## 과제 후보

| 과제 | 연결 |
|---|---|
| 실제 상품 CSV/JSON 읽기·검증·저장 | 코디 |
| 시계열 생성·분리·시각화 | 이상탐지 |
| Tensor·autograd·Dataset·MLP·학습/검증·저장/복원 | Vision/이상탐지 |
| 추천 기록 CRUD·SQL·HTTP | Structured Bloom |
| 작은 기억 검색·구조화 출력·행동 검증 | 캐릭터 |

최초 상태는 과제 리뷰 전입니다. 기존 저장소의 함수가 있다는 이유로 완료 체크하지 않습니다.

완료 기준: 자신의 말로 설명하고, 작은 기능 변경을 수행하고, 실행 결과를 확인하고, 어느 프로젝트에 적용했는지 기록합니다.
