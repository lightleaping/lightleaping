# 코디 추천·보드 서비스

상태: 기존 참고 코드 검토·첫 구현 준비. 면접 활용: 제외, 본인 재구현·검증 후 재검토.

## 문제와 목표

사용자가 기준 의류와 스타일·예산을 정하면 실제 상품에서 함께 입을 조합을 추천하고, 선택 상품의 실제 사진을 한 장의 코디 보드로 출력합니다.

- 입력: 실제 상품 ID·사진·카테고리·가격 등 확인된 정보, 사용자 조건.
- 출력: 추천 상품 ID 목록, 선택 이유, 상품과 대응되는 코디 보드.
- 범위: 실제 상품 일부로 시작. 가상 착용 제외.
- 재고·통화가 확인되지 않았다면 미확인으로 표시하고 판매 가능하다고 추정하지 않습니다.

## 현재 자료와 남은 일

참고 코드에는 이미지·텍스트 임베딩, 벡터 검색, 스타일/품질 분류, 배경 제거, 궁합 학습 코드가 있습니다. 이는 현재 본인이 새로 구현하거나 설명 능력을 검증한 기능을 뜻하지 않습니다.

새 추천→보드 흐름, 모델 실행, 배포, 추천 품질은 아직 이 포트폴리오에서 검증되지 않았습니다.

## 구현 단계

- [ ] 실제 상품 3개를 ID·이미지·메타데이터로 연결.
- [ ] 선택한 실제 사진을 한 장에 배치하고 상품 ID와 결과를 함께 저장.
- [ ] 카테고리·예산·확인된 판매 조건으로 후보 필터링.
- [ ] 색상·스타일 규칙으로 추천 기준선 구현.
- [ ] Vision 임베딩을 직접 설명하고 추천에 적용.
- [ ] 독립적인 궁합 라벨/평가로 개선 효과 확인.
- [ ] 추천·보드 API, 실패 처리, 실행 문서 정리.

## 계획 구조

실제 상품 목록 → 이미지 전처리·특징 추출 → 카테고리별 후보 → 조건·궁합 평가 → 세트 선택 → 실제 사진 배치 → 결과 저장/조회

## 평가 설계

- 상품 추적: 보드의 각 사진이 반환한 상품 ID와 일치하는가.
- 조건 준수: 카테고리 구성, 예산, 확인된 판매 조건을 지키는가.
- 보드 품질: 이미지 누락, 잘림, 겹침, 배경 제거 실패를 확인하는가.
- 추천 품질: 독립적인 사람 평가 또는 관련성 라벨로 기준선과 비교하는가.
- 유사 상품 검색 지표를 코디 궁합 성능으로 바꾸어 쓰지 않습니다.
- 행동 횟수로 정답을 만든다면 같은 집계값을 입력에 넣어 정답 산식을 재현하는 평가를 피합니다.

## 현재 결과

새 시스템 성능: 미측정. 공개 코드·데모: 아직 연결하지 않음. 본인 구현 기여: 첫 과제 리뷰 후 기록.

첫 미션 완료 기준: 실제 상품 3개의 이미지가 열리고, 파일과 정보를 ID로 연결하며, 이미지 접근과 판매 상태의 차이를 설명합니다.
