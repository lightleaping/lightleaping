## 프로젝트별 추가 자료

### 코디 추천·보드

- 실제 상품 ID, 원본 이미지 주소, 카테고리, 가격·통화, 확인 시점.
- 이미지 접근 가능 여부와 판매·재고 여부를 구별한 기록.
- 추천 세트의 상품 ID와 출력 보드를 연결한 결과.
- 유사 상품과 어울리는 조합을 구분한 평가 기준·라벨.
- 색상·스타일 규칙 기준선과 이후 모델 비교.
- 기존 코드의 출처와 본인이 다시 구현한 부분.

### 이상탐지·분석 Agent

- 실제 발생 사례의 출처, 증상, 확인된 원인, 적용 가능한 범위.
- 합성 시나리오의 정상 동작 가정, 변수·단위, 오류 발생 방식·강도.
- 운전/생성 단위 분리, 평가 전용 정답과 Agent 입력의 분리.
- 검출률·오탐·지연, 원인 후보 평가, 보고서 근거 일치 기록.
- 사건별 자동 보고서 예시와 연구 논문 원고를 각각 보관.

### Structured Bloom

- 기존 MVP와 Streamlit으로 재구현한 기능 비교.
- 입력 조건별 추천 결과, 저장 이력, 활동 완료·피드백 예시.
- Streamlit 재실행 시 중복 요청·중복 저장 방지 확인.
- 규칙 기반 추천과 AI 기능의 차이 및 평가.

### 캐릭터 엔진

- 세계관·페르소나 확정본과 버전.
- 상태 스키마, 허용 행동, 실행 전 검증 규칙.
- 기억 유무, 잘못된 행동, 중복 실행의 평가 사례.
- 검색 기억 → 행동 제안 → 검증 → 실행 → 상태 변경 기록.
