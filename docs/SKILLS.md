# 학습 역량표

이 표는 보유 기술 목록이 아니라 학습 목표입니다. 현재 상태는 모두 사용자 직접 구현·설명 리뷰 전입니다.

| 영역 | 직접 할 과제 | 연결 프로젝트 | 이해 확인 질문 | 현재 상태 |
|---|---|---|---|---|
| Python | 실제 JSON/CSV 읽기, 검증, 함수·클래스, 예외처리 | 전체 | 데이터가 없거나 잘못되면 어떻게 처리하는가? | 확인 전 |
| Git·HTTP·SQL | 변경 이력, 요청/응답, 기록 CRUD | 전체/P3 | 변경 복구와 잘못된 요청 처리 방법은? | 확인 전 |
| NumPy·Pandas | 자료형·결측·분리·전처리 | P1/P2 | 학습 데이터에서만 전처리를 fit하는 이유는? | 확인 전 |
| ML 평가 | 기준 모델, 지표, 임계값, 실패 분석 | P1/P2 | 어떤 오류가 늘었고 비교 조건은 같은가? | 확인 전 |
| PyTorch | Tensor, Dataset, MLP, 학습/검증, 저장/복원 | P1/P2 | gradient 계산과 parameter 갱신의 차이는? | 확인 전 |
| Vision | 이미지 전처리, 임베딩, 실제 상품 매핑 | P1 | 시각적 유사성과 코디 궁합은 어떻게 다른가? | 확인 전 |
| Streamlit | 입력, 세션 상태, 결과, 중복 저장 방지 | P3 | 화면 재실행과 DB 저장을 어떻게 구분하는가? | 확인 전 |
| FastAPI·DB | 요청 검증, 서비스 계층, 이력·피드백 | P1/P3/P4 | 실패했을 때 저장 상태가 일관되는가? | 확인 전 |
| 품질·실행 | 필요한 pytest, 로그, 환경변수, Docker | 서비스 | 다른 환경에서 실행하고 실패를 진단할 수 있는가? | 확인 전 |
| LLM·RAG | 구조화 출력, 근거 검색, 기억 저장/조회 | P2/P3/P4 | 근거가 없을 때 어떻게 처리하는가? | 확인 전 |
| Agent | 상태, 도구, 유효성 검사, trace, 평가 | P2/P4 | 제안과 실제 실행·상태 변경을 어떻게 분리하는가? | 확인 전 |

LangGraph, PostgreSQL 등은 실제 필요와 진도에 맞춰 선택합니다. 사용하지 않은 라이브러리는 완료 기술 목록에 넣지 않습니다.

기술이 여러 프로젝트에 걸치면 과제를 중복 계산하지 않고 해당 구현과 설명 기록을 연결합니다.
