## 운영 순서

1. 프로젝트 대화에서 작은 과제를 직접 구현합니다.
2. 실행 결과, 본인이 작성한 부분, 설명 가능 여부를 기록합니다.
3. 전체 조율 대화에 미션 요약을 전달합니다.
4. STATUS와 해당 프로젝트 문서를 먼저 갱신합니다.
5. 공개할 수 있는 변경만 프로필 README에 반영합니다.
6. 면접 활용 기준을 통과한 범위만 이력서·면접 답변에 추가합니다.

진행률은 임의의 백분율로 표시하지 않습니다. 기능·이해·재현의 완료 조건을 사용합니다.
