# 진행 현황

기준일: 2026-09-10

**기존 GitHub 프로젝트는 전부 면접 활용에서 우선 제외합니다.** 다시 공부하고 직접 구현·설명·재현한 범위만 별도 리뷰 후 복귀합니다. 기존 코드와 수치를 새 프로젝트의 완료 증거로 사용하지 않습니다.

| ID | 프로젝트 | 자료·설계 | 본인 신규 구현 | 실행 재현 | 설명 확인 | 면접 활용 | 다음 미션 |
|---|---|---|---|---|---|---|---|
| P1 | 코디 추천·보드 | 참고 코드 검토, 실제 상품 후보 있음 | 미확인 | 새 보드 미검증 | 미확인 | 제외 | 실제 상품 3개를 ID·이미지·메타데이터로 연결 |
| P2 | 이상탐지·분석 Agent | 범위 확정, 대상/첫 오류 미확정 | 미확인 | 미검증 | 미확인 | 제외 | 대상 시스템·관측 변수·사례·정상 동작 정의 |
| P3 | Structured Bloom | Streamlit 재구현 방향 확정 | 새 버전 미확인 | 새 버전 미검증 | 미확인 | 제외 | 기분·시간 입력 → 활동 추천 화면 |
| P4 | 캐릭터 엔진 | 목적·최소 범위 정리 | 미확인 | 미검증 | 미확인 | 제외 | 캐릭터 1명의 상태·허용 행동 정의 |
| L1 | 공통 기본기 | 학습 방식 정리 | 과제 결과 미확인 | 미검증 | 미확인 | 별도 대표작 아님 | Python·PyTorch 현재 수준 확인 |

‘미확인’은 구현이 없다고 단정하는 표현이 아닙니다. 현재 갱신에 사용할 증거가 제출되지 않았다는 뜻입니다.

## 상태 변경 규칙

1. 준비: 문제·입출력·자료·완료 기준을 정리했습니다.
2. 구현 중: 사용자가 작성/수정한 코드와 작업 기록이 있습니다.
3. 실행 확인: 입력·명령·결과가 남아 있습니다.
4. 이해 확인: 사용자 설명과 독립적인 변경 과제를 리뷰했습니다.
5. 평가 완료: 고정된 조건과 기준 모델에 대한 측정이 있습니다.
6. 면접 활용 가능: [면접 활용 기준](INTERVIEW-GATE.md)을 해당 범위가 통과했습니다.

코드 실행만으로 이해 확인이나 면접 활용 상태를 올리지 않습니다. GPT가 작성한 요약 자체도 증거가 아닙니다.

## 이번 갱신

- 기존 프로젝트는 대표 성과·면접 자료에서 우선 제외.
- 새 네 프로젝트와 공통 학습을 구분.
- 실제 상품 사용, XR·하드웨어 제외, Agent·자동 원인 분석·보고서 필수, Streamlit 재구현을 반영.
- 새로운 모델 학습·배포·평가를 완료했다고 주장하지 않음.
